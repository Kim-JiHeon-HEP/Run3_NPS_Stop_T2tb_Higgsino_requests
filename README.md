# Run3 NPS Stop T2tb Higgsino-like requests

T2tb with m(chi1+) - m(chi10) = 0.35, 1, 5 GeV and prompt chi1+ decays: BR from arXiv:2312.08087 for dM <= 1 GeV,
the chi1+ decay of the approved Run 2 T2tb samples (SUS-RunIISpring16FSPremix-00018) for dM = 5 GeV.
Made from the RunIII2024Summer24 T2tb fragment (NPS-RunIII2024Summer24FSGenPremix-00103), on its mass grid.

- `fragments/`: 114 fragments (38 mStop x 3 dM, 517 points per dM)
- `csv/`: Run3Summer22/22EE (176.90M events each), RunIII2024Summer24 (194.47M events)
- Gridpacks: existing ones on cvmfs
